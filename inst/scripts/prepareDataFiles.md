# Prepare Data Files

## Prepare Test GPML file
The `test-gpml.gpml` file was manually created in the [PathVisio](https://pathvisio.org/) (version 3.3.0) software. 
This GPML file is used to test whether PinPath correctly visualizes the different interactions and shapes.

## Prepare Lung Cancer Data
The `data-lung-cancer.csv` file was created with the `prepareLungCancerData.R` script. 
This dataset is used to generate the example pathway and network diagrams in the vignettes.
