## Installation
Use the following R code to install the PinPath web app (PinPath-Shiny):

```r
# install "remotes" package
install.packages("remotes")
      
# Install PinPath from GitHub
remotes::install_github("SyNUM-lab/PinPath_Shiny") 
```
<br>

## Run the app
With the following line, you can run the PinPath-Shiny locally:
```r
PinPath_Shiny::runPinPath()
```
